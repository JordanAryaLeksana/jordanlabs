KONTEKS DESAIN DAN INTERFACE SAAT INI
Jordan AI Portfolio — Jordan Arya Leksana
Snapshot implementasi: 17 Agustus 2026

TUJUAN DOKUMEN

Dokumen ini merangkum desain dan komponen interface yang benar-benar digunakan oleh repository saat ini. Dokumen ini dapat diberikan kepada GPT lain sebagai konteks brainstorming. Bedakan kondisi aktual di sini dari proposal redesign baru. Repository tetap menjadi source of truth jika implementasi berubah setelah tanggal snapshot.


1. RINGKASAN PRODUK DAN DESIGN THESIS

Website ini adalah portfolio personal Jordan Arya Leksana dengan Jordan AI sebagai interface utama. Produk memakai prinsip “AI-first, tetapi bukan AI-only”. Visitor dapat mengeksplorasi portfolio melalui percakapan atau melalui halaman konten tradisional.

Karakter visual saat ini:

- clean product/portfolio UI dengan atmosfer cinematic Korean startup;
- dark cinematic hero di setiap route, diikuti content surface yang mengikuti light/dark theme;
- human, technical, restrained, youthful, dan recruiter-friendly;
- Jordan AI menjadi focal point di Home;
- navigasi manual, CV, GitHub, LinkedIn, dan theme ditempatkan dalam satu utility menu;
- surface memakai rounded corners, border tipis, shadow ringan, dan translucent backdrop secara selektif;
- bukan dashboard, bukan cyberpunk, bukan terminal UI, dan bukan fanpage Start-Up.

Bahasa visualnya dapat diringkas sebagai:

“Interactive AI portfolio workspace inside a cinematic startup atmosphere.”


2. INFORMATION ARCHITECTURE AKTUAL

Route publik utama:

- / — Home dan main stage Jordan AI.
- /about — profil, background, transisi pengalaman, tech stack, dan aktivitas GitHub.
- /projects — featured project.
- /projects/[slug] — technical project/case-study detail.
- /experience — timeline pengalaman, role, kontribusi, dan teknologi.
- /contact — contact hero, kanal kontak, dan form pembuat draft email.

Tidak ada Research sebagai primary navigation. Research diperlakukan sebagai project atau bagian dari technical case study.

Route /docs-visualization masih tersedia sebagai area development-only/noindex untuk eksperimen atau dokumentasi visual. Komponen retro yang dipakai di sana bukan representasi utama UI publik.


3. GLOBAL APPLICATION SHELL

Root layout terdiri dari:

- font variables dan global theme tokens;
- PortfolioChatProvider yang mempertahankan satu conversation state lintas route;
- content route yang sedang dibuka;
- PersistentChatDock pada semua halaman selain Home.

Theme:

- theme default diinisialisasi sebelum hydration untuk mencegah flash;
- preferensi disimpan di localStorage;
- light memakai cream base dan dark memakai ink base;
- ThemeToggle berada di utility menu;
- theme behavior harus dipertahankan dalam ide redesign berikutnya.

Header publik memakai PortfolioHeader:

- kiri: “Jordan Arya Leksana” dan label “SOFTWARE / AI ENGINEER”;
- nama merupakan link kembali ke Home;
- kanan: satu tombol pill “Menu”;
- hierarchy sengaja minimal agar Jordan AI atau konten page tetap dominan.

UtilityMenu:

- desktop berupa side sheet dari kanan, mobile menjadi full-screen sheet;
- berisi About, Projects, Experience, dan Contact;
- resource area berisi Download CV, GitHub, LinkedIn, dan ThemeToggle;
- mengunci body scroll saat terbuka;
- mendukung Escape, focus trap, focus restoration, dan backdrop click;
- tidak menampilkan banyak tombol resource di first layer Home.

Footer:

- menunjukkan lokasi, local time, identitas Jordan, dan link kembali ke Jordan AI;
- memiliki bottom padding besar agar tidak bertabrakan dengan persistent chat trigger;
- tampil editorial dan sederhana, bukan footer dengan banyak kolom marketing.


4. SCENE SYSTEM AKTUAL

SceneBackdrop adalah satu reusable backdrop abstraction untuk seluruh page. Saat ini hanya satu gambar scene yang dirender per hero. Tidak ada lagi gambar owner yang ditumpuk di atas scene.

Mapping scene aktif:

- Home: /scenes/home-studio.webp
- About: /scenes/about-rooftop.webp
- Projects: /scenes/projects-build-room.webp
- Project detail: /scenes/projects-build-room.webp
- Experience: /scenes/experience-demo-day.webp
- Contact: /scenes/contact-night.webp

Perilaku scene:

- image full-bleed dengan object-cover dan object-center;
- dua overlay gelap menjaga kontras teks: overlay horizontal dan vertical;
- subtle camera drift selama 18 detik bila motion diizinkan;
- prop subdued dapat menurunkan opacity scene;
- ketika conversation Home aktif, opacity scene turun menjadi 0.24 agar chat lebih terbaca;
- prefers-reduced-motion menonaktifkan transisi yang tidak perlu.

Folder public/scenes/owner tetap menyimpan kandidat gambar milik owner, tetapi file-file tersebut tidak dipakai oleh runtime UI dan tidak ditumpuk pada scene.


5. HOME DAN INTRO EXPERIENCE

Home adalah viewport penuh dengan tinggi 100svh dan minimum height untuk menjaga composition. Susunan utamanya:

IntroSequence
  -> SceneBackdrop(home)
  -> PortfolioHeader
  -> ChatWidget variant workspace

IntroSequence berjalan sekali per session dan mempunyai dua fase:

- LoadingScreen: greeting phrases bergantian;
- BrandReveal: reveal identitas/brand;
- user dapat memilih SKIP INTRO atau ENTER;
- overlay keluar dengan fade/scale transition;
- reduced-motion dihormati.

Intro bersifat presentational dan tidak memiliki AI/business logic.


6. JORDAN AI WORKSPACE

Jordan AI mempunyai dua presentation state.

A. Welcome state

- label “PORTFOLIO ASSISTANT” berwarna coral;
- heading besar “Jordan AI”;
- copy pendek tentang kemampuan assistant;
- empat suggested actions:
  1. Evaluate Jordan for an AI Engineer role
  2. Show Jordan's strongest AI project
  3. Get Jordan's CV
  4. Help me contact Jordan
- composer tetap jelas di bagian bawah;
- cinematic scene masih cukup terlihat.

B. Active conversation state

- welcome state diganti conversation history;
- scene menjadi lebih subdued;
- messages menjadi prioritas visual;
- status submitted/streaming muncul sebagai teks kecil dengan pulse coral;
- auto-scroll menjaga response terbaru terlihat;
- composer tetap mudah dijangkau;
- transisi welcome-to-conversation memakai Framer Motion dan menjadi instan pada reduced motion.

Komponen inti Jordan AI:

- PortfolioChatProvider: pemilik state useChat dan lifecycle tool/navigation.
- ChatWidget: memilih workspace atau dock variant.
- AgentWorkspace: layout conversation + composer dan penanda conversation-active.
- AgentConversation: welcome state, message history, streaming status, dan error state.
- AgentHomeState: greeting dan deskripsi kemampuan.
- SuggestedActions: prompt starter yang benar-benar dapat dikirim.
- AgentComposer: input dan send button.
- MessagePartRenderer: memilih presentation berdasarkan text/data/tool part.
- ChatMessageBubble: membedakan pesan user dan assistant.
- PersistentChatDock: companion AI di content pages.

Composer Home:

- surface rounded-2xl, border tipis, ink-panel transparan, backdrop blur, dan shadow;
- input satu baris dengan text-size 16px di mobile untuk menghindari keyboard zoom;
- send memakai reusable IconButton;
- spacing bawah menghormati safe-area-inset-bottom.

Composer dock:

- lebih compact;
- menempel di bawah panel dengan border top;
- tetap menghormati safe area mobile.

Message styling:

- pesan user: compact rounded bubble berwarna pine, rata kanan;
- response assistant: editorial block transparan dengan border coral di kiri, rata kiri;
- assistant tidak selalu dibungkus giant bubble;
- formatting inline sederhana mendukung bold dan italic;
- error ditampilkan sebagai assistant message yang dapat dibaca screen reader.


7. PERSISTENT CHAT COMPANION

PersistentChatDock tidak dirender di Home karena Home sudah memiliki workspace penuh.

Pada content route:

- kondisi tertutup: floating rounded button “Ask Jordan AI” di kanan bawah;
- kondisi terbuka desktop: panel maksimal sekitar 28rem x 38rem di kanan bawah;
- kondisi terbuka mobile: full-screen 100svh;
- panel mempunyai header “Jordan AI” dan tombol minimize;
- mobile mengunci body scroll;
- Escape menutup panel;
- input langsung menerima focus saat panel dibuka;
- focus kembali ke trigger setelah ditutup;
- conversation tetap sama ketika berpindah route karena provider berada di root layout.


8. GENERATIVE UI DAN TOOL RESULT

Jordan AI bukan hanya text chat. MessagePartRenderer dapat merender structured/generative UI berdasarkan tool atau trusted data.

Jenis result yang aktif:

- navigation status/action;
- CV download card;
- external resource card untuk resource terverifikasi;
- contact card;
- project filter result atau controlled error;
- skill filter result atau controlled error;
- portfolio knowledge/evidence;
- structured role evaluation;
- fallback untuk tool error yang tidak dikenali.

ToolResultSurface adalah wrapper visual bersama:

- max-width 3xl;
- rounded-2xl;
- border tipis;
- tokenized surface dengan backdrop blur dan shadow;
- header berisi Badge label dan optional metadata;
- body mempunyai spacing responsif.

Prinsip rendering:

- structured data menjadi source of truth untuk result UI;
- prose model tidak diduplikasi bila structured card sudah cukup;
- canonical URL, project, skill, dan contact data berasal dari application config/tool result;
- navigation tool dapat membuka route, project detail, scroll ke section, dan highlight section;
- section highlight memakai outline frame-green sementara dan menghormati reduced motion.

10. UI PRIMITIVES AKTUAL

Typography

- big-header: Aliens and Cows, terutama untuk display/experimental area;
- header/display: Space Grotesk;
- text dan mono: Space Mono;
- UI publik lebih mengandalkan Space Grotesk untuk heading dan Space Mono untuk body/technical labels;
- Typography component mengontrol semantic element, variant, size, weight, italic, dan class override.

Button

- reusable link atau button primitive;
- mempunyai primary, secondary/ghost variants sesuai consumer;
- dipakai untuk CTA/resource/form action.

IconButton

- semantic button dengan accessible label;
- dipakai pada send, minimize, dan compact controls.

Badge

- label kecil dengan semantic color variants: brick, pine, slate, mustard, coral;
- digunakan untuk category, status, technology, dan tool-result header.

Pill

- interactive compact control;
- dipakai pada tech-stack tabs dan mempunyai active state.

Section

- reusable max-width content section dan optional reveal behavior;
- menjaga horizontal padding/layout konsisten.

ThemeToggle

- mengubah light/dark theme dan menyimpan pilihan user.


11. MOTION SYSTEM AKTUAL

Framer Motion dipakai untuk state transition dan entrance yang punya makna:

- FadeIn;
- HoverLift;
- StaggerContainer dan StaggerItem;
- intro LoadingScreen/BrandReveal;
- welcome-to-conversation transition;
- optional ColorBlockReveal/ParallaxShape pada area tertentu atau eksperimen.

Motion harus tetap restrained. prefers-reduced-motion dihormati pada scene, conversation transition, hover transforms, section highlight, dan intro behavior.

13. SHAPE, SURFACE, DAN SPACING

Walaupun komentar lama “flat-retro” masih ada di globals.css, implementasi publik saat ini sudah menggunakan restrained rounded product surfaces.

Radius token aktif:

- sm .375rem
- md .625rem
- lg .875rem
- xl 1.125rem
- 2xl 1.5rem
- 3xl 2rem
- full 9999px

Pattern surface utama:

- border currentColor dengan opacity rendah;
- bg-ink-panel/80–85 pada dark cinematic areas;
- bg-[var(--bg-raised)] pada content areas;
- backdrop-blur hanya pada surface yang butuh readability;
- shadow digunakan untuk elevation, bukan glow;
- rounded-full terutama untuk status dot, badge/pill tertentu, dan floating controls.


14. RESPONSIVE DAN ACCESSIBILITY

Responsive:

- memakai svh untuk mobile browser viewport;
- layout dua/tiga kolom berubah menjadi satu fokus pada mobile;
- persistent dock menjadi full-screen di mobile;
- utility menu menjadi full-width sheet di mobile;
- safe area dipakai untuk composer, dock, dan menu;
- composer input memakai ukuran yang aman terhadap mobile keyboard zoom;
- images memakai Next Image dan responsive sizes.

Accessibility:

- semantic header, nav, main, section, article, form, dan aside;
- visible focus menggunakan frame-green;
- focus trap dan focus restoration pada utility menu;
- Escape menutup overlay/menu/dock;
- aria-label pada icon-only button dan conversation regions;
- aria-live untuk chat/form status dan error;
- touch target umumnya minimal 44–48px;
- reduced-motion support;
- text/scene contrast dijaga melalui overlay dan surface.


15. PRESENTATION VS BUSINESS LOGIC

Boundary yang harus dipertahankan saat brainstorming:

- scene dan layout hanya presentation;
- PortfolioChatProvider menghubungkan chat state dengan browser actions;
- RAG, model selection, evaluation, retrieval, dan server tools berada di lib/app API, bukan di visual component;
- route, project ID, dan section ID berasal dari shared tool types;
- stable DOM ID tidak boleh diganti hanya untuk estetika;
- canonical content berasal dari config/content/tool results;
- Jordan AI dapat memilih intent/tool, tetapi application yang memiliki truth dan menjalankan action.


16. FILE/AREA YANG BUKAN REPRESENTASI UI PUBLIK UTAMA

- public/scenes/owner/*: hanya arsip kandidat owner, tidak dirender saat ini.
- components/interfaces/retro/*: primitive lama/eksperimental yang masih dipakai pada docs visualization, bukan visual vocabulary wajib untuk public portfolio.
- components/interfaces/ui/Typography/aliens-cows/*: termasuk font dan preview/license assets; jangan menganggap semua gambar preview itu asset UI.
- app/docs-visualization/*: development visualization, bukan primary route untuk visitor.


17. CONSTRAINT UNTUK BRAINSTORMING LANJUTAN

Ide baru sebaiknya:

- mempertahankan Jordan AI sebagai primary interaction;
- tidak mengubah AI/RAG/tool lifecycle hanya untuk styling;
- mempertahankan persistent conversation lintas route;
- mempertahankan stable route dan section IDs;
- memakai satu focal scene, bukan menumpuk beberapa gambar;
- membiarkan file owner tetap tersimpan tetapi tidak otomatis merendernya;
- mempertahankan typography family, color tokens, theme, accessibility, dan reduced motion;
- tidak menambah UI library atau animation dependency tanpa kebutuhan fungsional;
- tidak mengubah Home menjadi landing page tradisional penuh CTA;
- tidak mengubah assistant menjadi dashboard penuh card;
- menghindari neon, cyberpunk, terminal-heavy styling, gradient berlebihan, glassmorphism berat, dan card-within-card;
- mengutamakan responsive composition dan clear mobile hierarchy;
- tetap recruiter-friendly dan mudah memahami identitas Jordan tanpa harus mengirim prompt.


18. PERTANYAAN BRAINSTORM YANG DISARANKAN UNTUK GPT

Gunakan konteks di atas lalu diskusikan:

1. Bagaimana memperkuat first impression Jordan AI tanpa menambah visual noise?
2. Bagaimana membuat perpindahan welcome state ke active conversation terasa lebih intentional?
3. Apakah hierarchy setiap page sudah cukup berbeda secara naratif meskipun memakai shell yang konsisten?
4. Bagaimana memperjelas evidence dan technical depth lewat generative UI tanpa berubah menjadi dashboard?
5. Bagaimana meningkatkan mobile composition, terutama composer, chat history, dan scene crop?
6. Surface atau card mana yang dapat dikurangi agar hasil lebih editorial?
7. Bagaimana membuat tool action terasa seperti workspace bereaksi, bukan sekadar status text?
8. Bagaimana meningkatkan hiring/recruiter scanability tanpa membuat manual navigation mendominasi Home?

Saat memberi proposal, minta GPT mengelompokkan setiap ide sebagai KEEP, REFACTOR, MERGE, REMOVE, atau ADD, serta menyebutkan component/file aktual yang terdampak. Proposal tidak boleh mengasumsikan bahwa gambar owner masih ditumpuk karena implementasi tersebut sudah dihapus.
