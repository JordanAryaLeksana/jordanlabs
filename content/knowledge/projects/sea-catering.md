# SEA Catering

## Project overview

SEA Catering is a live full-stack meal subscription platform built by Jordan Arya Leksana (live at https://sea-catering-beta.vercel.app, repository https://github.com/JordanAryaLeksana/sea-catering). Customers browse meal plans, create subscriptions, pause or cancel them and follow delivery schedules.

## Features and tech stack

- Next.js App Router, TypeScript, Prisma, NextAuth, deployed on Vercel.
- Email and Google sign-in with NextAuth.
- Role-based user and admin dashboards with business metrics.
- Validated API routes over a Prisma data model for users, subscriptions, testimonials, contacts and deliveries.
- Automated test coverage and production usage metrics are not documented.
