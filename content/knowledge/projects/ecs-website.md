# ECS Website

## Project Overview

The Embedded System and Cyber Physical Laboratory (ECS) Website is a full-stack web platform built to manage laboratory events, information, and user interactions for the ECS lab at Institut Teknologi Sepuluh Nopember.

## Timeline

July 2024 – July 2025, spanning two roles: Tech Lead Frontend for the first version, then IT Project Manager for the 2.0 rebuild.

## Key Contributions

- Directed frontend development of the first version of the official ECS website and event portals as Tech Lead Frontend, building responsive, reusable UI components with Next.js and Tailwind CSS.
- Led the end-to-end development of ECS Website 2.0 as IT Project Manager, overseeing feature design, timelines, and team coordination using Agile methodology.
- Managed a cross-functional team of developers and designers to build the new official ECS website and event platforms, including the EPTA dashboard.
- Designed and implemented key features including event management and internal dashboards.

## Planned Future Features

- Equipment borrowing system.
- 3D printing payment and checkout flow.
- EPTA 2.0 enhancements.

## Technologies

TypeScript, Python, Next.js, Tailwind CSS. Backend migrating from Django to Nest.js; database migrating from MySQL to MongoDB.

## Impact

Increased knowledge among laboratory assistants and supported the development of internal laboratory products.
