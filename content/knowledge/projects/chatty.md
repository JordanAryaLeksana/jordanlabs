# Chatty

## Project overview

Chatty is a cross-platform Flutter chat application built by Jordan Arya Leksana (repository https://github.com/JordanAryaLeksana/chatappFlutterFirebase). It provides Google sign-in with Firebase Authentication and real-time conversations backed by Cloud Firestore streams: deterministic chat IDs, live message streams, new-chat creation, conversation ordering, sending and deleting messages. Navigation uses GoRouter. There is no public store build or hosted demo.
